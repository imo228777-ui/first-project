# Speakly

Speakly is a mobile-first language-learning web app prototype.

## Current prototype

- Responsive dashboard and mobile navigation
- German beginner lesson with multiple-choice questions
- XP, levels, daily goal, streak and coins
- Vocabulary list with search and flashcards
- Cosmetic shop with locally persisted purchases
- Profile and settings
- Progress stored in the browser with localStorage

## Run

Open `index.html` in a browser. No build tools or dependencies are required.

## Notes

This is the first front-end MVP. Accounts, cloud sync, real multiplayer clubs, server-side leaderboards, and offline/PWA support are not implemented yet.
